# Telco Customer Churn - Lab 1

## Overview
This repository contains the Jupyter Notebook for Lab 1: Telco Customer Churn Data Exploration and Preprocessing. 

## Tasks Completed
- **Data Preprocessing:** Converted Churn (Yes/No) to 1/0, converted `TotalCharges` to numeric, and removed null values.
- **Data Exploration:** Analyzed customer demographics and service usage against churn rates (Gender, Senior Citizen, Partner, Dependents, Phone Service, Contract, Paperless Billing, and Payment Method).

## Key Findings
- Month-to-month contracts and electronic check payments have the highest churn rates.
- Senior citizens and customers without partners/dependents are more likely to churn.
- Gender and basic phone service do not significantly impact churn.
